Política de Privacidad y Términos de Servicio

Aplicación: Planificador de Tareas

URL: https://planificadortareas.lovable.app

Política de Privacidad

Esta aplicación accede a Google Classroom únicamente para leer las tareas del alumno autenticado. No se almacenan datos en servidores externos. Toda la información se guarda localmente en el navegador del usuario (localStorage). No se comparten datos con terceros.

Términos de Servicio

El uso de esta aplicación implica la aceptación de estos términos. La aplicación se ofrece de forma gratuita para uso personal de estudiantes. El desarrollador no se hace responsable de pérdidas de datos almacenados en el navegador.

Contacto

Para cualquier consulta relacionada con la privacidad, contacta con el desarrollador a través de la aplicación.
